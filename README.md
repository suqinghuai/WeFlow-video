# WeFlow导出html格式对于缺失视频文件补充的插件

## 项目介绍

本工具用于处理从「WeFlow」工具导出的 HTML 聊天记录。导出的 HTML 中，大多数视频消息仅显示为 `[视频]` 占位文本，且散落在备份目录中的 mp4 视频文件没有按消息关联。

工具会自动完成以下工作：

1. 解析 HTML 文件中的聊天记录数据，提取所有视频消息（`[视频]`）的时间戳
2. 扫描同级目录下的所有 mp4 文件（排除 `_raw.mp4` 原始文件）
3. 根据时间戳匹配每条视频消息对应的视频文件（选择时间差最小的 mp4）
4. 将匹配的视频复制到 HTML 项目的 `media/videos/` 目录，并重命名为 `{消息ID}_{哈希值}.mp4`
5. 将 HTML 中的 `[视频]` 占位文本替换为可播放的 `<video>` 标签
6. 目前仅使用weflow 4.3.1版本在 Windows 10 电脑上测试过，其他操作系统未测试。

处理完成后，直接在浏览器中打开 HTML 文件即可正常播放视频。

## 快速开始

### 面向使用者（使用 exe 文件）

1. 将 `main.exe` 放置在聊天记录备份目录（即包含 HTML 项目子文件夹和 mp4 文件的那个目录）
2. 双击运行 `main.exe`
3. 程序会自动扫描子目录中的 HTML 文件和散落的 mp4 文件，完成匹配与替换
4. 运行结束后，在浏览器中打开 HTML 文件验证视频是否正常播放

目录结构示例：

```
聊天记录备份目录/
├── main.exe              ← 放在这里
├── 某个HTML项目文件夹/
│   ├── index.html
│   ├── media/
│   │   └── videos/       ← 视频会输出到这里
│   └── ...
├── 2026-08/
│   ├── xxxx.mp4
│   └── ...
└── ...
```

### 面向开发者（从源码运行）

```bash
# 进入项目目录
cd <项目目录>

# 激活虚拟环境
venv\Scripts\activate          # Windows
source venv/bin/activate        # Linux/Mac

# 运行程序
python main.py
```

### 打包为 exe

```bash
# 安装 PyInstaller
pip install pyinstaller

# 打包（单文件 + 控制台模式）
pyinstaller --onefile --console main.py

# 生成的 exe 位于 dist/main.exe
```

## 实现方法

1. **定位工作目录**：通过 `sys.frozen` 判断运行模式，打包后以 exe 所在目录为根，开发时以脚本所在目录为根
2. **查找 HTML 项目**：遍历工作目录的一级子目录，找到包含 `.html` 文件的那个子目录
3. **解析消息数据**：用正则提取 HTML 中嵌入的 `window.WEFLOW_DATA` JSON 数据
4. **收集 mp4 文件**：递归扫描工作目录下所有 `.mp4` 文件，排除 `_raw.mp4` 原始文件，按文件修改时间排序
5. **时间戳匹配**：对每条视频消息，在有序 mp4 列表中用二分查找定位时间戳最接近的候选，再从前后各 2 个候选中选取时间差最小的
6. **复制 & 重命名**：将匹配的 mp4 复制到 `media/videos/` 目录，命名为 `{消息ID}_{原文件名去掉扩展名}.mp4`
7. **更新 HTML**：将 HTML 中对应 `[视频]` 的字符串替换为 `<video>` 标签，保持 JSON 转义格式
